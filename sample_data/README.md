# DEMO / SYNTHETIC sample data

В этой папке допускаются **только** искусственные, обезличенные примеры.

- Не размещайте реальные выгрузки инвентаризации.
- Не размещайте отчёты с фактическими остатками и суммами магазинов.
- Для CI/локальных тестов фикстуры создаются программно в `tests/`.

Реальные `*.xlsx` / `*.csv` игнорируются `.gitignore`.
