# Руководство по входному файлу

## Поддерживаемые форматы

- Инвентаризация: `.xlsx` (предпочтительно), `.xls`
- Оприходование: `.xlsx` / `.xls` с колонками закрытия смены

## Инвентаризация — обязательные маркеры шапки

| Маркер |
|--------|
| Документ.Подразделение |
| Количество книжное |
| Количество фактическое |
| Сумма излишек |
| Сумма недостача |

Структура строк (outline Excel):

1. Магазин / подразделение  
2. `Инвентаризация <номер> от ДД.ММ.ГГГГ [ЧЧ:ММ:СС]`  
3. Номенклатура с количествами и суммами  

Время **08:00:00** → автор «ревизор»; иное время → «оператор».

## Оприходование

Колонки:

- Закрытие смены количество  
- Закрытие смены сумма  

Сопоставление с инвентаризацией — только по **точному** наименованию внутри склада.

## Что нельзя загружать

- Файлы вида `Анализ_*.xlsx` (уже готовый отчёт модуля)
- Пустые или повреждённые книги
- Выгрузки без TDSheet-заголовков

## Эталон иерархии

Встроен в `data/master_hierarchy.json` (источник — шаблон без производства).  
Повторная загрузка шаблона на Cloud не обязательна.
