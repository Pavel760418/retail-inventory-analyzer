# Руководство пользователя

## Аномалии книжных сумм (Release 4)

Программа отдельно фиксирует пустые ячейки:

- **Сумма книжная (нормативная)**
- **Сумма фактическая (нормативная)** ← «книжная фактическая» в терминах отчёта

| Тип | Что это | Что делать |
|-----|---------|------------|
| Аномалия 1 | Нет нормативной, есть фактическая | Проверить себестоимость / почему пересчёт ушёл в излишки |
| Аномалия 2 | Нет обеих сумм | Критично: позиция не даёт недостач/излишков по сумме |
| Аномалия 3 | Только фактическая; имя есть в других магазинах | Сверить с другими складами / ручной ввод |

Лист отчёта: **«Аномалии»**. Кратко — на Сводке и в Выводах.

## Проверка цен между магазинами (Release 4)

Для наименований, которые встречаются в **двух и более** магазинах:

1. находятся пересекающиеся позиции (точное наименование);
2. считается **цена**, не сумма:
   - цена нормативная = Сумма книжная (нормативная) ÷ Количество книжное;
   - цена фактическая = Сумма фактическая (нормативная) ÷ Количество фактическое;
3. цены сравниваются попарно между магазинами.

На листе «Проверка цен» для прозрачности показаны и кол/сумма (исходники), и рассчитанные **ЦЕНА** — сравнение идёт только по ценам.

Статусы: совпадает / незначительное / заметное / требует проверки.

## Оприходование излишков (Release 4)

После инвентаризации загрузите второй Excel — оприходование при закрытии смены.

Нужные колонки:
- Закрытие смены количество
- Закрытие смены сумма

Правила:
- сопоставление **только точное** по наименованию;
- только внутри своего склада / подразделения;
- при связи с недостачей статус выделяется отдельно;
- несопоставленные позиции видны на листе «Оприходование излишков».

## Иерархия и категории

Категории подставляются **только** из встроенного эталона `data/master_hierarchy.json`
(исходник — `Шаблон_иерархия.xlsx`). Загружать справочник при каждом запуске не нужно.

Если товар не найден:

1. В отчёте категория = «Не найдено в справочнике»
2. Позиция попадает на лист «Вне справочника»
3. Keyword-эвристика не применяется

См. [hierarchy.md](hierarchy.md).

## Что делает программа

Строит аналитический отчёт по сетевой инвентаризации:

- сводка излишков и недостач;
- **перекрытие пересорта** только внутри однородных товарных групп;
- **чистые недостачи** (не объяснены однородным пересортом);
- рейтинг магазинов (классы A/B/C);
- аномалии книжных сумм и проверка цен (R4);
- сверка оприходования смены (R4);
- хронические проблемные позиции;
- план мероприятий по сценариям СЦ-1…СЦ-7;
- детализация по каждому магазину.

## Какой файл загружать

Нужна **исходная** выгрузка инвентаризаций сети (обычно лист вроде TDSheet), где есть:

- подразделения (магазины);
- документы вида `Инвентаризация <номер> от <дата>`;
- строки номенклатуры с количествами и суммами.

**Не загружайте** файлы, уже названные `Анализ_…xlsx` — программа их отклонит.

## Streamlit

1. Откройте приложение.
2. В сайдбаре задайте период (дней) и при необходимости конечную дату.
3. Загрузите Excel инвентаризации.
4. Загрузите Excel оприходования излишков.
5. Нажмите **Запустить анализ Release 4**.
6. Просмотрите блоки аномалий / цен / оприходования (есть фильтры).
7. Скачайте отчёт.

На телефоне и на компьютере интерфейс адаптивный (`layout=wide`); таблицы
прокручиваются горизонтально.

## CLI

```bash
python main.py
```

Выберите сначала файл инвентаризации, затем файл оприходования.
Отчёт сохранится рядом с исходником как `Анализ_сеть_<имя>_<timestamp>.xlsx`.
