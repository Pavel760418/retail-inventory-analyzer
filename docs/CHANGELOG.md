# Release notes — Release 4 (v4.0.0)

## Добавлено

- Второй входной файл: **оприходование излишков при закрытии смены**
  (`Закрытие смены количество`, `Закрытие смены сумма`)
- Модуль `src/capitalization.py`: парсинг, точный match, изоляция складов
- Лист Excel **«Оприходование излишков»**
- Модуль `src/anomalies.py`: три типа аномалий книжных сумм
  - тип 1 — нет книжной нормативной (риск нулевой с/с / излишки из пересчёта)
  - тип 2 — нет обеих книжных сумм (**критично**, итог искажён)
  - тип 3 — только фактическая; нужна сверка по другим складам
- Лист Excel **«Аномалии»**
- Модуль `src/price_compare.py`: сравнение книжных цен между магазинами
  по **точному** наименованию (без fuzzy)
- Лист Excel **«Проверка цен»**
- KPI аномалий / цен / оприходования на **Сводка**, блок в **Выводы**,
  колонки в **Рейтинг магазинов**
- Streamlit UX: блоки аномалий, проверки цен, оприходования + фильтры
- CLI: второй выбор файла после инвентаризации
- Тесты `tests/test_capitalization.py`, `tests/test_anomalies_prices.py`
- Версия пакета `4.0.0`

## Изменено

- Пайплайн отчёта: шаги 1–8 (аномалии + цены + оприходование)
- Парсер: флаги `книжная_норм_отсутствует` / `книжная_факт_отсутствует`
  (без изменения числовых расчётов излишков/недостач)
- `generate_conclusions(...)` принимает `anom_summary` и `price_summary`
- README / deployment / architecture под полный Release 4

## Сохранено (не сломано)

- Встроенная эталонная иерархия `data/master_hierarchy.json`
- Отключение keyword-классификации категорий
- Лист «Вне справочника»
- Текущая бизнес-логика перекрытий, рейтинга, мероприятий
- Формат и названия прежних листов отчёта

## Исправлено / усилено

- Явный запрет смешивания складов при сверке оприходования
- Неоднозначный маппинг склада → `uncertain_store`
- Пустые книжные суммы больше не «молчат» — фиксируются на отдельном листе
