# Release summary — v4.0.0 (Release 4)

## Цель релиза

Дополнить действующий модуль (без переписывания базовой механики):

1. Встроенная эталонная иерархия номенклатуры.
2. Сверка **оприходования излишков** при закрытии смены.
3. Фиксация **аномалий** книжной нормативной / фактической суммы.
4. **Проверка цен** между магазинами по точным наименованиям.

## Где иерархия

`data/master_hierarchy.json` + `src/master_hierarchy.py` (без повторной загрузки шаблона).

## Аномалии книжных сумм

| Тип | Условие | Смысл |
|-----|---------|--------|
| Аномалия 1 | Нет нормативной, есть фактическая; имя уникально для склада | Риск нулевой с/с, пересчёт → излишки |
| Аномалия 2 | Нет ни нормативной, ни фактической | Критично: нет расхождений по сумме |
| Аномалия 3 | Нет нормативной, есть фактическая; имя есть в других магазинах | Ручной пересчёт, нужна сверка |

Лист: **«Аномалии»**. Кратко — на Сводке / в Выводах / в Рейтинге.

## Проверка цен между магазинами

- Только точное совпадение наименования.
- Сравниваются unit-цены книжные нормативные и фактические.
- Попарно магазин₁ ↔ магазин₂ (без смешивания).
- Статусы: совпадает / незначительное / заметное / требует проверки.

Лист: **«Проверка цен»**.

## Оприходование

1. Инвентаризация → 2. файл оприходования → 3. map склада → магазина →
4. точный match имени внутри склада → 5. флаг связи с недостачей.

Лист: **«Оприходование излишков»**.
